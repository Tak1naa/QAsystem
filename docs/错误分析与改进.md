# 错误分析与改进

## 评估口径修复

旧程序将耗时为0的记录排除，快速运行会导致分母变化。新版按成功状态计数，所有测试样本参与准确率分母，失败单独记录。三模式汇总的键名已统一，去掉“混合模式最佳”等预写结论。完整标注样本计算实体误提取、漏提取和micro F1，部分标注样本仅报告覆盖情况。

## 数据修订

开发样本存在标准词不一致和推断性标注。轴箱与轮对轴箱装置、车轮直径与轮径属于归一化问题；原样本中的抗蛇行减振器与一系垂向减振器、跑合试验与动平衡试验则是概念混淆。修订清单保留了修改前后值和原因，不能把这些数据修订全部算作算法提升。

## 独立题首次结果

24题首次评估中，分类、缺失判断和路由各23题正确，实体完全匹配20题正确。实体TP=47、FP=4、FN=2，micro precision=92.16%，recall=95.92%，F1=94.00%。原始预测固定在evaluation/holdout_first/report.json。

| 样本 | 原因 | 处理 |
|---|---|---|
| H002 齿轮箱剩磁量上限是多少mT | 英文缩写忽略大小写，把mT识别为磁粉探伤MT | 工艺缩写MT保留大小写区分 |
| H008 车轮组装前应该如何清洗 | “车轮组”短别名截取了组装的第一个字 | 删除歧义别名，保留轮对与轮对组成 |
| H015 空气弹簧高度低于190 | 原完整标注用了泛称高度，程序输出弹簧高度 | 另存2.1回归标注，首次数据和预测不覆盖 |
| H024 汽车轮胎应该充多少气 | “汽车轮胎”中部件跨词命中车轮 | 增加明确非领域短语排除，避免实体跨词误提取 |

这些题在修复后属于回归题，不能用修复后的全通过结果替换首次独立表现。

## 性能与后续工作

规则处理的主要成本是词典匹配。当前词典按文件修改时间缓存，避免每题重复读盘，元数据单独记录加载、提取、分类、完整性和路由耗时。旧预测重放仅用于重新评分，不能把字典查找耗时当作旧算法耗时。前后不同时间采集的耗时不作严格速度提升证明。

接入真实LLM后，应固定模型、Prompt、样本版本、并发数与预热方法，分别报告成功在线调用、规则直出与回退的准确率和P50/P95耗时。当前置信度未经校准，混合阈值0.65只是初始策略，应使用独立验证集选择，不能根据本次开发题直接宣称最优。

仍需扩充真实问句、否定现象、并列部件和复杂数值范围的测试。当前规则能保留数字和单位，但没有建立数值与指标的对应关系，亦不处理跨轮对、车型、检修等级等条件的知识推理。
